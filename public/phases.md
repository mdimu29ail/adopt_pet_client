# Development Roadmap

## Phase 1: Foundation
*   Setup Project (Frontend/Backend).
*   Initialize Supabase/Database.
*   Implement Authentication (Login/Register/Github).
*   Setup Protected Routing.

## Phase 2: Pet Adoption Core
*   Pet listing UI (Cards, Filters).
*   Pet details page.
*   Adoption submission form.

## Phase 3: Donation Campaigns
*   Campaign CRUD (Create/Edit/View).
*   Donation payment integration (Stripe).

## Phase 4: User & Admin Dashboards
*   User Dashboard (Profile, History, My Listings).
*   Admin Dashboard (Pet Management, Role Management).

## Phase 5: Refinement
*   UI/UX Polish (Animations, Loading states).
*   Error handling/Form validation.
*   Comprehensive testing.
